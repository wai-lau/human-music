`9e1be9b`. Focus: security; structure, DRY and extensibility; linters and
end-to-end tests. Severity is for this extension's real users: the worst
outcome is skipping a real person's music, then leaking listening data.

Checked and safe: no HTML sinks or `eval`; no `externally_connectable` or
`web_accessible_resources`, so pages can't message the worker; the worker's
`refresh` message takes only a known list id; `executeScript` injects only
packaged files; host permissions are the two music sites plus one fixed GitHub
path, with `https://*/*` optional and asked per site on a click; list data goes
into `Map`s, so `__proto__` names can't pollute anything; user keywords are
escaped before becoming regexes and list names never are; the log stays in
local storage and leaves only through your own export; the Firefox build adds
no permissions and keeps the default CSP.

## Linters and end-to-end tests (added)

- **`npm run lint`**: ESLint 9.39 with the recommended rules plus `no-var`,
  `eqeqeq`, the `eval` family and a ban on `innerHTML`-style sinks for
  `extension/`. Tests and e2e lint clean. `background.js` has 58 findings left
  (D6), held until the two Qwen tasks that edit it merge.
- **`npm run e2e`**: Playwright 1.61 starts Chromium with `extension/`
  unpacked in a fresh profile. Stand-in pages for both sites are served by
  the test from the selectors in the spec; no host name resolves, so nothing
  reaches the real sites, an account or the list download (a test proves it).
  21 tests: skip once and log, a person's song plays, never skip, a paused tab
  waits, auto-skip off, lookahead removal, hiding, Block artist, button
  placement, pause; on Spotify, match by ID, Queue panel opened once and left
  closed when closed, removal, hiding; in the popup, built-in list, an artist
  added reaching an open tab, "Wrong: never skip", backup import refusing
  non-https lists and showing names as text, settings. A mutation run (two
  rules broken in a copy, `HM_E2E_EXT=<copy>`) turned exactly those two tests
  red.
- **`npm test`**: unchanged (`node`, no install).
- **Dev tools only.** `package.json` holds the dev tools; `extension/` still
  has no dependencies and no build step.
- **Gaps.** No shell linter (shellcheck isn't installed); Mozilla's
  `web-ext lint` was refused by permissions earlier; Playwright can't load
  extensions in Firefox, so the Firefox build has no end-to-end run. Node 18
  holds ESLint at an unsupported 9.39 (offer 3).
